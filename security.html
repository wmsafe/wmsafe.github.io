SECURITY CONTROLS

安全能力与责任边界

以审慎、可验证的语言说明产品能力，不以架构机制代替全系统安全治理。

◎

指定业务范围

以指定 IP:Port 发布资源，避免默认交付整个网段。

◇

凭证分层

客户端账号用于登录，资源仍需对应 Link ID 与通信口令。

◈

传输保护

产品白皮书描述了端侧加密及密文传输机制；实际强度依实现和部署决定。

▣

本地端口访问

默认可绑定 127.0.0.1；按需配置全网卡监听。

↺

授权撤回

停用或删除发布规则，以结束对应业务的后续接入。

⚑

主机侧防护

业务自身鉴权、终端安全、密钥管理与网络访问控制仍需持续维护。

关于 0.0.0.0

绑定 0.0.0.0 意味着在所有可用网络接口监听，并非仅对当前局域网开放。实际可访问范围受主机防火墙、路由和网络隔离影响。仅在可信受控环境中按需启用。
