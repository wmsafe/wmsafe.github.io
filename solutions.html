PRACTICAL USE CASES

按场景交付恰当的访问范围

各场景均以指定业务资源为授权范围，便于控制访问权限。

01
Web / OA / ERP

远程办公与内部业务访问

业务需求

员工需要从不同地点访问 ERP、OA、知识库等内部系统。

守望者的工作方式

在内网可达的发布端指定业务 IP:Port，远端通过资源凭证建立本地映射，继续使用原有浏览器或应用。

02
SSH / RDP / TCP

第三方厂商临时排障

业务需求

外部专家只需完成某项维护任务，不必接触整张内部网络。

守望者的工作方式

按任务发布对应 SSH、RDP 或 TCP 资源，使用独立 Link ID 与通信口令；Windows RDP 可从工作台直接进入远程桌面，维护结束后撤销对应资源授权。

03
MySQL / SQL Server / TCP

核心数据库隔离运维

业务需求

数据库管理人员需要通过专业工具访问内部数据库。

守望者的工作方式

发布指定数据库端口，访问端映射本地监听，并使用既有数据库客户端连接。

04
127.0.0.1 / 0.0.0.0

外勤现场与团队共享

业务需求

同一可信现场内，多台设备可能需要访问同一授权业务。

守望者的工作方式

访问端可按需配置 0.0.0.0 监听，经局域网 IP 共享入口；建议仅在受控网络并结合防火墙策略使用。
